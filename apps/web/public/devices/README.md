# Bilder von sichergestellten Geraeten

Hier liegen die Bilder, die `files[].imagePath` eines Geraets im Case-JSON
referenziert — z. B. `apps/web/public/devices/case-01/img-2207.jpg` (Story #20).

**Der Ordner ist absichtlich leer**, aus denselben Gruenden wie bei den
Szenenbildern (`../scenes/README.md`): keine echten Assets im Repo waehrend der
MVP-Phase. Die Dateiansicht zeigt solange einen Platzhalter mit der
Bildbeschreibung (`caption`) — das ist der geplante Zustand, kein Fehler.
