# Asservatenfotos

Hier liegen die Bilder, die `evidence.imagePath` im Case-JSON referenziert —
z. B. `apps/web/public/evidence/case-01/notebook-kuendigung.jpg`.

**Der Ordner ist absichtlich leer**, aus denselben Gruenden wie bei den
Szenenbildern (`../scenes/README.md`): keine echten Assets im Repo waehrend der
MVP-Phase. Die Detailansicht zeigt solange einen Platzhalter mit dem
Beweis-Titel — das ist der geplante Zustand, kein Fehler.
