# Szenenbilder

Hier liegen die Tatort-Bilder, die `scene.imagePath` im Case-JSON referenziert —
z. B. `apps/web/public/scenes/case-01/buero-412.jpg` fuer `/scenes/case-01/buero-412.jpg`.

**Der Ordner ist absichtlich leer.** Echte Bild-Assets werden in der MVP-Phase nicht
committet (Copyright und Repo-Groesse, siehe `CLAUDE.md`). Solange kein Bild da ist,
zeigt die Szenen-Ansicht den Platzhalter mit dem Szenennamen — das ist der geplante
Zustand, kein Fehler.

Wer ein Bild zum Ausprobieren braucht: lokal ablegen, **nicht** committen.
