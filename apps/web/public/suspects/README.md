# Porträts der Verdächtigen

Hier liegen die Bilder, die `suspect.imagePath` im Case-JSON referenziert —
z. B. `apps/web/public/suspects/case-01/daniel-keller.jpg`.

Asservaten: keine echten Assets im Repo während der MVP-Phase. Die Liste zeigt
solange die Initialen der Person — das ist der geplante Zustand, kein Fehler.
